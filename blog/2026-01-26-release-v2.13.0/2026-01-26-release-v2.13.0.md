We are pleased to announce the release of **POJO-actor v2.13.0** and **actor-IaC v2.13.0**.

This release brings Java plugin support, JSON State variable expansion fixes, and the new WorkflowReporter for actor-IaC.

<!-- truncate -->

## POJO-actor v2.13.0

### Features

- **JSON State Variable Expansion**: Fixed `${json.key}` variable expansion in `ActorRef.expandVariables()` to properly strip 'json.' prefix before lookup
- **JSON State API**: Added `putJson`/`getJson` methods to ActorRef for workflow state management
- **Plugin Support**: Added `CallableByActionName` interface for plugin support
- **Dynamic Actor Loading**: Improved `DynamicActorLoaderActor` with JAR loading and child creation capabilities

### Testing

- Added comprehensive unit tests for variable expansion and JSON state functionality

## AptLockChecker Plugin (actor-IaC-plugins)

A new plugin repository has been created with the **AptLockChecker** plugin for detecting hung apt processes:

- Parses `ps -eo pid,etimes,args` output to detect hung apt processes
- Configurable threshold (default: 1 hour)
- Returns human-readable age format (e.g., `2h`, `3d`)
- Designed for use with actor-IaC workflows

### Example Usage

```yaml
# Load plugin JAR
- actor: loader
  method: loadJar
  arguments: ["../actor-IaC-plugins/target/actor-IaC-plugins-1.0.0.jar"]

# Create plugin actor
- actor: loader
  method: createChild
  arguments: ["this", "aptChecker", "com.scivicslab.actoriac.plugins.aptcheck.AptLockChecker"]

# Check for hung processes
- actor: aptChecker
  method: check
  arguments:
    psOutput: "${result}"
    hostname: "${json.hostname}"
```
