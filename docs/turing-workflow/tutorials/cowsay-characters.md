# Cowsay Characters

Turing-workflow can display Cowsay characters during workflow execution. Specify the character with the `--cowfile` option.

## Usage

```bash
./turing_workflow.java run -w ./workflows/deploy --cowfile tux
```

## Displaying the Character List

You can check the list of available characters via CLI:

```bash
./turing_workflow.java run --cowfile list
```
